# Entre estar y PODER estar

Experiencia interactiva que explora los sonidos de la alcaldía Cuauhtémoc como una forma de recorrer y construir visualmente el territorio.

## Tecnologías

- HTML
- CSS
- JavaScript

## Cómo interactuar

Mantén presionado el botón durante siete segundos para escuchar un fragmento sonoro. Mientras escuchas, la cartografía visual se construye progresivamente.
